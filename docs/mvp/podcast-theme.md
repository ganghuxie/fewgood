# 播客主题

`podcast`（播客）是 fewgood 的第二个主题。它采用创作者优先的上传列表采集：不使用 `search.list`，只允许已列出的频道及 handle 通过 `channels.list(forHandle)` 解析。

候选必须至少 20 分钟、至多 4 小时；访谈/长谈取近 180 天，专题解读取近 365 天，少量常青的知名内容最多 730 天。池子要求订阅数至少 1,000、180 天内上传和来源依据（官方/节目品牌可豁免）。排序偏向清晰、有实质的谈话与较新的内容，降权标题党和营销式“改变人生”承诺；新闻切片、预告、炒币/暴富和纯娱乐吐槽会排除。

每个子主题最多 6 条、同频道最多 2 条，目标配比为深度访谈/专题解读/名家长谈 `3/2/1`。所有展示条目都保留可展开的推荐依据；没有足够好内容时明确显示“宁缺毋滥”。
